# Effect van Beeldresolutie op YOLOE-26m

## Over dit onderzoek

Dit project onderzoekt het effect van beeldresolutie op de detectienauwkeurigheid van het YOLOE-26m-model. Het doel is om inzicht te krijgen in de invloed van verschillende beeldresoluties op de prestaties van het model.

In deze repository zijn de gebruikte code, datasets, modelbestanden en onderzoeksresultaten verzameld.

## Inhoud van de repository

De repository bestaat uit de volgende onderdelen:

| Bestand/map | Beschrijving |
|---|---|
| `AAI - Block 1 - Mini Symposium - Research - Data - Dutch.ipynb` | Notebook met de data-analyse en voorbereidende stappen |
| `AAI - Block 1 - Mini Symposium - Research - Model - Dutch.ipynb` | Notebook met de modelimplementatie en experimenten |
| `Dataset/` | Gebruikte dataset |
| `Dataset YAML/` | YAML-configuratiebestanden voor de dataset |
| `yoloe-26m-seg.pt` | Gebruikt YOLOE-26m-segmentatiemodel |
| `LVIS - Trainingsset - Labels.json` | Annotaties van de LVIS-trainingsset |
| `LVIS - Validatieset - Labels.json` | Annotaties van de LVIS-validatieset |
| `Samenvatting Resultaten.csv` | Overzicht van de onderzoeksresultaten |

## Code uitvoeren en bekijken

De notebooks zijn opgeslagen als Jupyter Notebooks (`.ipynb`).

**Voor de beste leesbaarheid wordt aangeraden om de notebooks te openen in Visual Studio Code (VS Code).**

Hierdoor zijn de code, Markdown-teksten, grafieken en uitvoer overzichtelijker te bekijken dan rechtstreeks op GitHub.

Om de notebooks te openen:
1. Download of clone deze repository.
2. Open de projectmap in Visual Studio Code.
3. Open het gewenste `.ipynb`-bestand.
4. Gebruik de Jupyter-extensie om de notebooks te bekijken en eventueel uit te voeren.
